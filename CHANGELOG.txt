PHASE 3: DATA-DRIVEN CORE PRODUCT LOOP
================================================================================
A. Extended Database Architecture (lib/db.js & data/db.json)
   - Extended existing file database to maintain separate top-level collections:
     * users: [{ id, name, email, phone, passwordHash, token, createdAt }]
     * journals: [{ id, userId, title, entry, mood, tags, createdAt }]
     * moods: [{ id, userId, mood, createdAt }]
     * activities: [{ id, userId, type, completedAt }]
   - Did not introduce secondary databases; retained lightweight, fast file store.

B. New REST API Endpoints Created
   1. POST /api/moods
      - Authenticates via httpOnly session cookie `eira_session`.
      - Derives userId strictly from verified session. NEVER trusts client userId.
      - Strictly validates mood as integer between 1 and 5 (1=LOW, 2=NOT GREAT, 3=OKAY, 4=GOOD, 5=GREAT).
      - Rejects invalid values (0, 6, strings, floats) with HTTP 400.
      - Rejects unauthenticated calls with HTTP 401.
      - Returns HTTP 201 with saved mood object.
   2. GET /api/moods
      - Authenticated endpoint returning user's mood telemetry sorted descending.
      - Supports `?limit=` query parameter.
   3. POST /api/activity
      - Records completion of wellness tools (breathing, grounding, focus, games).
      - Persists id, userId, type, and completedAt.
   4. GET /api/activity
      - Returns authenticated user's activity completions.
   5. GET /api/dashboard/summary
      - Consolidated server-calculated endpoint providing real-time synchronization:
        * metrics: checkInsThisWeek, journalsThisWeek, activitiesThisWeek (past 7 days)
        * weeklyTrend: 7-day calendar array ending today
        * insight: deterministic descriptive pattern analysis
        * recommendation: personalized tool suggestion based on latest check-in
        * latestMood: most recent mood record

C. Deterministic Wellbeing Insight & Metrics Engine (lib/insights.js)
   - Created pure mathematical utility:
     * calculateWeeklyMetrics: Filters records within Date.now() - 7 * 86400 * 1000.
     * buildWeeklyTrend: Constructs 7 calendar days ending today.
       - Missing days remain strictly null and render as "—" (NEVER treated as 0 or negative).
     * generateInsight: Deterministic non-diagnostic check-in pattern analysis:
       - 0 check-ins: "START WITH TODAY. LOG YOUR FIRST CHECK-IN TO SEE YOUR PERSONAL TREND."
       - 1 check-in: "ONE CHECK-IN LOGGED. COME BACK TOMORROW TO BUILD YOUR WEEK."
       - 2 check-ins: "CHECK IN FOR A FEW MORE DAYS TO SEE YOUR TREND."
       - 3+ check-ins: Compares earlier vs later average:
         * Trending Up (+0.5+): "YOUR RECENT CHECK-INS ARE TRENDING UPWARD."
         * Trending Down (-0.5-): "YOUR RECENT CHECK-INS HAVE BEEN LOWER THAN EARLIER THIS WEEK."
         * Steady: "YOUR RECENT CHECK-INS HAVE BEEN FAIRLY STEADY."
       - STRICT RULE: Absolutely zero psychiatric or diagnostic language.
     * getPersonalizedRecommendation:
       - Mood 1-2 (LOW, NOT GREAT): Suggests "TRY A GROUNDING EXERCISE →" (/wellness)
       - Mood 3 (OKAY): Suggests "TRY A BREATHING SESSION →" (/wellness)
       - Mood 4-5 (GOOD, GREAT): Suggests "TRY A FOCUS SESSION →" (/wellness)

D. Connected Homepage & Story Dashboard (app/page.js & page.module.css)
   - Connected 5 mood buttons to /api/moods with live loading states ("SAVING...").
   - Added live toast confirmation banner with clear error vs confirmed styling.
   - Refreshes dashboard calculations immediately via loadDashboardSummary() without page reload.
   - Visualizes YOUR WEEK with 3 real calculated metric boxes:
     * CHECK-INS THIS WEEK
     * JOURNALS THIS WEEK
     * WELLNESS SESSIONS
   - Visualizes YOUR TREND with real 7-day Neo-Brutalist grid:
     * Day labels (SUN..SAT), TODAY badge, solid color score pills, dashed missing slots.
     * Legend mapping 1 LOW (#FF5500) through 5 GREAT (#D4FF00).
   - Visualizes EIRA NOTICED:
     * High-visibility quote box with deterministic insight and direct action link.
   - Complete state coverage:
     * Unauthenticated prompt with direct login link
     * Loading state: "LOADING YOUR WEEK..."
     * Error state: "COULDN'T LOAD YOUR CHECK-INS. [TRY AGAIN]"
     * Empty state: "NO CHECK-INS YET — START WITH TODAY"

E. Connected Wellness Lab (app/wellness/page.js)
